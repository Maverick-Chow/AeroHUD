# AeroHUD

An animated on-screen HUD for [AeroSpace](https://github.com/nikitabobko/AeroSpace) workspace switches, built as a [Hammerspoon](https://www.hammerspoon.org) Spoon. It shows every workspace and its apps when you switch, and animates windows as you move them between workspaces.

![AeroHUD demo](assets/demo.gif)

## Install

Requires [AeroSpace](https://github.com/nikitabobko/AeroSpace) and [Hammerspoon](https://www.hammerspoon.org).

```sh
curl -fsSL https://github.com/Maverick-Chow/AeroHUD/releases/latest/download/install.sh | bash
```

See [docs/INSTALL.md](docs/INSTALL.md) for what the script does and other ways to install, and [docs/CONFIGURATION.md](docs/CONFIGURATION.md) to customize the HUD.
